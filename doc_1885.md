## Testing the Integration

### Order Injections with Sandbox

We have a sandbox environment to send orders to your application. Check how to use it in **Tools Introduction > Sandbox Environment**.

### Using a Test Store

We provide you a way to create a fake order on the customer's app to a test store so you can see if the order's information is being sent correctly, test how to confirm, and cancel the order. To do so, follow the steps below:

1. If you don't have a test store yet, create one following the steps in **Tools Introduction > Application Management**.

2. Have in hands a customer's test credentials. This is a fake customer account that is able to see the test stores on 99Food's app (C-App). If you didn't receive this credentials, ask our team.

3. Check the possible store locations below depending on your country. You'll have to use a nearby location as a customer.

4. Follow the flow exemplified on the chart below.

5. Check this [step by step guide](https://dpubstatic.udache.com/static/dpubimg/0bSJSfSGj_7ggQzF7UKWO.pdf) if you need more details.


- **Test Store City**: Goiânia
- **Test Store Address**: Avenida T 2, 1922, Setor Bueno, Goiânia, Goiás. 74215-010
- **Test Store Coordinates**: Longitude -49.2811349, Latitude -16.6918214
