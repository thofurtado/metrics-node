Mapa do Ecossistema Metrics

Cada caixa é um app; cada linha é uma conversa entre dois deles. Toque num app ou numa linha para ver o que passa, de quanto em quanto tempo, o que acontece quando cai e o que está errado hoje. As jornadas mostram um acontecimento atravessando vários apps, passo a passo.

De onde vêm os dados: o Raio-X do Ecossistema (10/10/2026), com cada ligação comprovada no código (arquivo e linha nos relatórios de cada parte), e os números de funções, defeitos e aulas de cada app. Versões: as publicadas em 10/10.

Como fica atualizado: os dados moram no Atlas (metrics-node/docs/atlas/ecossistema.json). A cada versão fechada que muda uma ligação, uma versão no ar ou os números de um app, o arquivo é corrigido na mesma tarefa e o gerador do Atlas monta esta página de novo, junto com as regras e as aulas.
