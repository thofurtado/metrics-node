## Before Going Live

### Pre-Production Checks

Before being able to create a production app and bind real stores to your integration, you need to check if all mandatory functions are integrated

#### Token - Mandatory

You need to be able to **get and refresh the store’s token** and have implemented a routine to **automatically refresh the token** when receiving an error response indicating that the `auth_token` is expired. **Read more** in **Authorization API**.

#### Order

##### Order Flow - Mandatory

Understand the order flows as shown in **Integration Guide > Our Orders API Module**.

##### Order Injection - Mandatory

- Be able to receive the `orderNew` webhook and send the response to the order injection as shown in **Integration Guide > Webhooks > Webhooks Responses**.

- Be able to parse the bigints correctly. More about this in **Integration Guide > Webhooks**.

- Be able to display in the system and in the receipt **both** the `order_id` and `order_index` fields (**Order API > Get Order Details**).

- If the integrated store accepts orders in cash, be able to process the `shop_paid_money` field (**Order API > Get Order Details**).

- Be able to process the differences in structures of the JSON for stores with 99Food’s delivery and self-delivery. The structures for price and receive address are different depending on the store’s type of delivery (**Order API > Get Order Details**).

- Be able to process the promotion information sent in the order JSON. Read more in **Order API > Promotions**.

- Be able to read and process the entire price structure.

##### Order Confirmation - Mandatory

Be able to confirm order by the API (**Order API > Confirm Order**).

##### Order Refuse/Cancellation - Highly Recommended

Be able to refuse/cancel order by the API (**Order API > Cancel Order**).

#### Webhook responses - Mandatory

Be able to respond to all webhooks as shown in **Integration Guide > Webhooks > Webhooks Responses**.

#### Request ids - Highly Recommended

For every call to our endpoints or the webhooks, we send a request id. This is the information you’ll need to open a ticket with support to investigate in case of errors. So we recommend keeping these request ids saved at least for some days.
